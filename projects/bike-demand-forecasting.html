Bike-Sharing Demand Forecasting

Graduate class project · team project with A. Hines

≈0.96test R² for the tuned neural network
0.91test R² before tuning
4model families compared

Problem

Bike-sharing systems need to know how many bikes will be rented each hour. This project forecast hourly demand in Seoul from weather, time of day, season, holidays, and whether the system was operating.

What I did

  • Compared an artificial neural network, a PyTorch LSTM on sliding-window sequences, XGBoost, and random forest.
  • Tuned the neural network with Ray Tune, XGBoost with staged grid search, and random forest with GridSearchCV.
  • Used correlation and feature-importance analysis to identify what drives demand.

Results

  • Tuning raised the neural network's test R² from 0.91 to about 0.96.
Team project; results reflect the team's work.

Tools: Python, PyTorch, Ray Tune, XGBoost, scikit-learn
