Connect your website editor

The website is built. The editor still needs an authentication provider before photo uploads can be saved to GitHub.

  1. Create or sign in to a free Netlify account. Configure a site and its GitHub OAuth provider following Decap’s GitHub setup instructions. Keep the public portfolio on GitHub Pages.
  2. Register the required GitHub OAuth application and place its secret only in the provider’s secure settings. Never put it in this repository.
  3. Update admin/auth.json: set site_domain to the configured provider site domain, and set enabled to true. The default provider URL is Netlify’s authentication service.
  4. In the GitHub repository, choose Settings → Pages → Source → GitHub Actions. The included workflow rebuilds the website from editor changes and publishes it.
  5. Open /admin/, sign in, upload a test image with a caption and description, save a draft, and publish. Verify the gallery and then remove the test photo.

Everyday updates

Open Website content → Gallery to add photos and albums. Use the other sections for homepage text, service roles, education, awards, navigation, and resume/CV files. Save drafts until ready, then publish. Allow the GitHub deployment to finish before checking the public site.

Uploaded media is stored in the repository. Use photos intended for public viewing; an unpublished gallery entry does not make its uploaded file private. For faster loading, upload web-sized JPEG or WebP photos, ideally under 2 MB.

The CMS is free software. Provider usage limits still apply; no paid service has been enabled for this site.
